# SDLC Artifact Map

This directory holds the approved artifacts produced by each phase of the Agentic SDLC defined in the project `CLAUDE.md`. Files are created only when their phase actually runs — nothing here is pre-generated.

| File | Produced during | Status |
|---|---|---|
| `user-story.md` | Legacy intake snapshot (historical; no longer a required Requirements input — current runs resolve the User Story from Jira, Confluence, or a supplied Word document) | Present |
| `requirements.md` | Requirements | Not yet created |
| `architecture.md` | Architecture | Not yet created |
| `adr/*.md` | Architecture (as needed) | Directory present, empty |
| `design-review.md` | Design Review | Not yet created |
| `impl-plan.md` | Implementation Planning | Not yet created |
| `code-review.md` | Code Review | Not yet created |
| `verification.md` | Verification | Not yet created |

See the root `CLAUDE.md` for the source-of-truth hierarchy, approval gates, and agent/skill/command responsibilities that govern how these files are produced and reviewed.
